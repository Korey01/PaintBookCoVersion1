# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in PaintBookCo, please report
it responsibly by emailing: o.a.alashe@paintbookco.co.uk

**Please do not report security vulnerabilities through public GitHub issues.**

## What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact

## Response SLA

- Acknowledgement within 2 business days
- Status update within 5 business days
- Fix timeline communicated within 10 business days

## Supported Versions

Only the current production release is supported.
